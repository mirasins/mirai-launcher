# Mirai — Descargas

Página estática independiente de la aplicación nativa. No requiere compilación ni JavaScript.

## GitHub Pages

Publicar la raíz de la rama gh-pages desde Settings → Pages → Deploy from a branch → gh-pages → / (root).

URL prevista tras activar Pages: https://mirasins.github.io/mirai-launcher/

## Actualizar descargas

Comprobar las releases públicas de los cinco repositorios Mirai. Editar las versiones y enlaces por plataforma en index.html; usar browser_download_url de cada asset sin reconstruirlo a partir del tag. No anunciar paquetes inexistentes. Actualizar la fecha de revisión. Los enlaces a Releases permiten consultar publicaciones posteriores.
